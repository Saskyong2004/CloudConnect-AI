ABOUT THE PROJECT

Simple communication, cloud powered.

CloudConnect allows users to submit contact messages and feedback through a web interface. The request is sent to an AWS API, processed by Lambda and stored in DynamoDB.

⚡

Serverless

Process requests without managing traditional servers.

🔗

API Powered

API Gateway connects the frontend with the backend.

🧠

AI Analysis

Sentiment, category, priority and key phrases are detected automatically.

AWS TECHNOLOGY STACK

Built using five AWS services.

01

Amazon S3

Hosts the static website files.

02

API Gateway

Receives HTTP contact requests.

03

AWS Lambda

Processes submitted form data.

04

Comprehend + Gemini

AI sentiment, summary and suggested replies.

05

DynamoDB

Stores messages with their AI results.
